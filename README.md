# Class Knowledge Hub

고등학교 학급 지식 공유 웹 플랫폼

## 1. 기능 요약
- 닉네임 기반 회원가입/로그인
- 관리자/일반 사용자 분리
- 교과목/단원별 게시판
- 게시물 유형: 개념 정리, 문제, 비법 노트, 오답 정리
- 문제 정답 확인 버튼
- 좋아요, 댓글, 신고
- 포인트/레벨 시스템
- 관리자 대시보드
- 레벨 기반 심화 자료 접근 제한
- 욕설/비하 표현 필터링
- 일일 포인트/좋아요/댓글 한도

## 2. 실행 전 준비
- Node.js 18 이상 설치
- npm 설치
